    คู่มือการใช้งาน

    อ่านตามลำดับได้เลยครับ ใช้เวลาไม่นาน

    1. เริ่มต้นใช้งาน 2. เพิ่มข้อมูลทีละแถว 3. วางข้อมูลจาก Excel 4. แก้ไข / ลบข้อมูล 5. ดู Dashboard 6. Export ไฟล์ 7. ข้อควรระวัง

    1 เริ่มต้นใช้งาน

    ไฟล์นี้เป็นเว็บเพจไฟล์เดียว (HTML) เปิดได้โดยการดับเบิลคลิกไฟล์ แล้วเลือกเปิดด้วยเบราว์เซอร์ เช่น Chrome หรือ Edge ไม่ต้องติดตั้งโปรแกรมเพิ่ม

    • ควรมีอินเทอร์เน็ตตอนเปิดไฟล์ครั้งแรก เพราะระบบต้องโหลดฟอนต์และไลบรารีกราฟจากอินเทอร์เน็ต
    • เก็บไฟล์นี้ไว้ใน ตำแหน่งเดิมที่แน่นอน (เช่น โฟลเดอร์ Desktop หรือโฟลเดอร์งานที่ไม่ย้ายบ่อย) เพราะข้อมูลที่กรอกจะผูกกับตำแหน่งไฟล์และเบราว์เซอร์ที่ใช้เปิด
    แนะนำ: เปิดด้วยเบราว์เซอร์เดิมทุกครั้ง และอย่าย้าย/เปลี่ยนชื่อไฟล์ ถ้าจำเป็นต้องย้าย ให้ Export ข้อมูลเก็บไว้ก่อน แล้วค่อย import กลับด้วยการวางข้อมูลจาก Excel ในไฟล์ใหม่

    2 วิธีเพิ่มข้อมูลทีละแถว

    ไปที่แท็บ 📝 บันทึกข้อมูล กรอกข้อมูลในฟอร์มด้านบน:

    1. เลือก วันที่
    2. ใส่ Name, Feed name, Channel
    3. ใส่เวลาเริ่ม-จบ (พิมพ์แบบข้อความ เช่น 1:00)
    4. เลือก Status: Pass / Fix / Issue / Wait
    5. กดปุ่ม "＋ เพิ่มรายการ" ข้อมูลจะไปโผล่ในตารางด้านล่างทันที

    3 วางข้อมูลจาก Excel ทีเดียวหลายแถว

    เหมาะเมื่อมีข้อมูลอยู่ใน Excel อยู่แล้วและอยากใส่เข้าระบบทีเดียวหลายบรรทัด

    1. ใน Excel ให้เรียงคอลัมน์ตามลำดับนี้: Date | Name | Feed name | Channel | Start | End | Status | หมายเหตุ
    2. เลือกช่วงเซลล์ที่ต้องการ แล้วกด Ctrl+C (หรือ Cmd+C บน Mac)
    3. กลับมาที่เว็บ กดปุ่ม "📋 วางข้อมูลจาก Excel"
    4. คลิกในกล่องข้อความแล้วกด Ctrl+V เพื่อวาง
    5. ระบบจะแสดงตัวอย่างข้อมูลที่แยกคอลัมน์ให้ดูก่อน ตรวจสอบว่าคอลัมน์ตรงกันไหม (แถวไหนมีปัญหาจะมีป้าย ตรวจสอบ ให้แก้ในตารางทีหลังได้)
    6. กด "ยืนยันเพิ่มข้อมูล" เพื่อนำเข้าทั้งหมดในครั้งเดียว
    ไม่จำเป็นต้องมีครบทุกคอลัมน์ก็ได้ ถ้าขาดคอลัมน์ไหนระบบจะเว้นว่างไว้ให้ไปเติมทีหลัง

    4 แก้ไข / ลบข้อมูล

    • แก้ไข: กดไอคอนดินสอ ✎ ท้ายแถว ข้อมูลจะขึ้นมาที่ฟอร์มด้านบนให้แก้ไข แล้วกด "บันทึกการแก้ไข"
    • ลบทีละแถว: กดไอคอนถังขยะ 🗑 ท้ายแถว
    • ลบหลายแถวพร้อมกัน: ติ๊กเลือกช่องหน้าแถวที่ต้องการ (หรือติ๊กที่หัวตารางเพื่อเลือกทั้งหมด) แล้วกดปุ่ม "ลบที่เลือก" ด้านบนตาราง

    5 ดู Dashboard และเลือกช่วงเวลา

    • รายสัปดาห์: ใช้ปุ่ม ‹ › เพื่อเลื่อนดูสัปดาห์ก่อนหน้า/ถัดไป
    • กำหนดช่วงเอง: เลือกวันที่เริ่มต้น-สิ้นสุดตามต้องการ
    • ทั้งหมด: ดูสรุปข้อมูลทุกช่วงเวลาที่มี

    การ์ดด้านบนสรุปจำนวนฟีดและสถานะ กราฟซ้ายแสดงจำนวน Pass/Fix/Issue/Wait รายวัน กราฟขวาแสดงว่าแต่ละ Channel ถูกใช้กี่ครั้งในช่วงที่เลือก และด้านล่างมีรายการที่ต้องติดตาม (รายการที่ไม่ผ่าน หรือมีหมายเหตุ) ให้ดูง่ายๆ โดยไม่ต้องไล่ดูทั้งตาราง

    6 Export ไฟล์

    1. ไปที่แท็บ 📝 บันทึกข้อมูล กดปุ่ม "⬇ Export"
    2. เลือกได้ว่าจะ Export เฉพาะรายการที่กรองอยู่ หรือทั้งหมด (ติ๊ก/ไม่ติ๊กช่องนั้น)
    3. เลือก Export เป็น CSV (เปิดได้ทั้ง Excel/Google Sheets) หรือ Excel (.xlsx) โดยตรง
    4. ไฟล์จะถูกดาวน์โหลดลงเครื่องตามค่าเริ่มต้นของเบราว์เซอร์ (ปกติคือโฟลเดอร์ Downloads)

    7 ข้อควรระวัง

    ข้อมูลทั้งหมดถูกเก็บไว้ในเบราว์เซอร์เครื่องนี้เท่านั้น (เทคโนโลยีที่เรียกว่า localStorage) ไม่ได้อัปโหลดขึ้นอินเทอร์เน็ตหรือเซิร์ฟเวอร์ใดๆ

    ผลที่ตามมาคือ:
    • ถ้าเปลี่ยนเครื่องคอมพิวเตอร์ หรือเปิดด้วยเบราว์เซอร์อื่น จะไม่เห็นข้อมูลเดิม
    • ถ้าล้างประวัติ/แคชของเบราว์เซอร์ ข้อมูลจะหายไปด้วย
    • ถ้าย้ายไฟล์ไปคนละตำแหน่ง (บางเบราว์เซอร์) อาจมองเป็นคนละไฟล์และไม่เห็นข้อมูลเดิม

    แนะนำ: กด Export เก็บเป็นไฟล์ Excel/CSV ไว้เป็นระยะ (เช่น ทุกสัปดาห์) เพื่อสำรองข้อมูลไว้เสมอ

    📋 วางข้อมูลจาก Excel

    คัดลอกข้อมูลจาก Excel ตามลำดับคอลัมน์: Date | Name | Feed name | Channel | Start | End | Status | หมายเหตุ แล้ววางในกล่องด้านล่าง (Ctrl+V)
